Дипломный проект · Python 3.10+

Прогнозирование АСПО

Программный комплекс для оптимизации обработок скважин на основе прогнозирования асфальтосмолопарафиновых отложений. Снижение затрат и простоев за счёт точной даты обработки.

Попробовать демо Архитектура

Демонстрация работы

Выберите сценарий скважины — программа покажет прогноз и рекомендуемую дату обработки.

Нажмите «Рассчитать прогноз», чтобы увидеть результат

Архитектура ПО

Модульная структура на Python — от ввода данных до отчёта.

📥

Ввод данных

Загрузка промысловых данных из CSV/Excel, ручной ввод параметров скважины.

🌡️

Расчёт температуры

Распределение температуры по стволу скважины, определение точки начала кристаллизации парафинов.

📊

Модель АСПО

Эмпирическая зависимость толщины слоя отложений от дебита, обводнённости и температуры.

📈

Визуализация

Графики прогноза, зоны риска, сравнение сценариев обработки.

📄

Отчёты

Экспорт в Excel/PDF с рекомендациями и экономическим эффектом.

⚙️

Стек

Python 3.10+, NumPy, SciPy, Pandas, Matplotlib/Plotly, Tkinter/PyQt/Streamlit.

Как запустить

git clone https://github.com/ваш-логин/apo-forecast.git
cd apo-forecast
pip install -r requirements.txt
python main.py
